# 动手做 TFH MOD

[English tutorials](README.en.md) · [研究文档目录](../README.md)

先装开发环境，做一个会弹对话框的小教程。运行时钩子放在后面。每课都写了代码放哪儿、怎么检查，以及目前查到哪一步。

| 顺序 | 动手内容 |
|---|---|
| 0 | [准备目录，跑公开源码](zh/00-start-here.md) |
| 1 | [给教程菜单加一关](zh/01-first-lesson.md) |
| 2 | [把一关扩成带对白的连战章节](zh/02-chapter.md) |
| 3 | [选 Arizona 加载大熊，给奥莉开强化](zh/03-hidden-boss.md) |
| 4 | [读取人物和对局属性，再改几个确定的属性](zh/04-properties.md) |
| 5 | [写一个只观察、不改玩法的钩子](zh/05-hooks.md) |
| 6 | [发送指令，接 UI，做发布前检查](zh/06-input-and-ui.md) |

本轮新写的 `hello.lua`、候选包生成器和训练观察器属于教学示例。合成测试、语法检查能在开发机上做；这组新示例还没有经过游戏内验证。历史上大熊替换、原生输入等成功记录的适用范围见原研究章节，不能用来替这些新文件背书。

包内原始 Lua、XML 和游戏资源需要你自己从有权访问的游戏副本取得。仓库里不附原包。运行时示例只认文档记载的 EXE 构建；检查失败就停下。
