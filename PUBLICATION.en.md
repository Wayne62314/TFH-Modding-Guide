# Publication scope, privacy and rights

[English index](README.en.md) · [中文原文](PUBLICATION.md)

This is a newly created public documentation repository, without imported private research Git history. Content includes original explanations, sanitized summaries, build-specific technical facts, public references and original teaching code, including a read-only observer and local candidate builder. Original game libraries are not included.

Excluded: private raw logs/local paths/process-absolute addresses; participant names/accounts; original replays and user-recorded combos; complete game scripts/archives/textures/FOIT; crash dumps; model weights; credentials; runtime environments.

The game, third-party projects and their assets remain the property of their respective rights holders. Investigate copies you are authorized to access and follow applicable licenses. Public visibility does not authorize redistribution of third-party assets. These notes do not select new licenses for existing projects or relicense third-party code.

No single repository-wide open-source license has currently been selected. Credit the source when referencing/quoting. For substantial copying, adaptation or relicensing of original documentation/examples, confirm specific permission with the maintainer first. Existing public projects' code follows their own repository declarations.

Examples concern authorized offline research. This repository does not distribute installable automatic-defense/throw-tech tools, network-unrestricted variants or anti-cheat bypasses. Do not disable security software to run unsigned tools.

Before contributing, check for secrets, packet captures, real-player identifiers, local paths and game assets. State the build and evidence level. New-version addresses need revalidation methods, not just replacement numbers.
