# 12 · 本构建原生入口与字段参考

[English](en/12-build-specific-reference.md)

**只适用于EXE SHA256 `03E20EECE23F39FB1012061A5A7FF92F4B63DA23EB8EB641CF6EE379CBCE373D` 的研究记录。** RVA相对已加载主模块；对象偏移相对已验证对象，不是进程绝对地址。不要为适配新版本删除校验。

表中“使用过”不等于SDK保证。不同实验限制不同；组合这些偏移并不自动得到安全程序。先读[原生方法](03-native-investigation.md)和[作用域](07-performance-and-prediction.md)。

## 入口/全局

| RVA | 本次用途 | 证据与边界 |
|---|---|---|
| 0x1772f40 | 战斗加载观察/待加载P1替换 | 公开角色工具使用，需匹配调用方 |
| 0x1773b84 | 隐藏角色替换允许的返回位置 | 调用方过滤，不是独立函数入口 |
| 0x1773720 | 外层重置完成后应用增强/控制器 | 公开工具校验其序言 |
| 0x8fbb0 | 原生字符串赋值路径 | 参数/分配器属本构建，不是通用memcpy |
| 0x1780f40 | 角色Flag setter布局参照 | 原生包装/实现交叉确认 |
| 0x189b7e0 | 场景根更新 | 必须核对主scene、更新参数、深度/线程/预测 |
| 0x17617a0 | native输入处理入口 | 采集角色实际输入 |
| 0x1775820 / 0x1775825 | 已验证输入调用位置 / 返回地址 | 前者用于私有输入替换，后者校验采集来源 |
| 0x1747110 | 按钮聚合规则参照 | 与手动ABCD及B+C对照，不是OS键码 |
| 0x3e3170 / 0x1795980 | 状态闭包构造 / 排队路径 | 公开三阶段实现使用；需状态表、所有权和正确线程 |
| 0x2b0d1e8 | 主scene指针位置 | 指针内容每次重新读取，不能永久缓存 |
| 0x2b0cc33 | 本次AI预测隔离使用的字节 | 需深度跟踪和回调重查，不代表完整网络判定 |

## Scene字段

| 偏移 | 本次读取类型 | 用途/限制 |
|---|---|---|
| +0x9e4 | u32 | 场景战斗类型；不能单独区分0的录像/实战 |
| +0x9c4 | u32 | 更新计数；入口/出口差值1是采样门槛 |
| +0xc48 | u32 | 阶段；7用作经验过滤，不是通用可行动标志 |
| +0xaa8 / +0xab4 | s32 | 当前P1/P2槽位；本次检查0..2、3..5 |
| +0xae0 + slot*8 | pointer | 由槽位找角色；检查空值、队伍及身份 |
| +0xa68 / +0xa70 | pointer | 对象池范围；本次步长0x14a0，有上限和存活检查 |
| +0x2028 | pointer | 当前模式对象；需先判断非空 |
| 模式对象+0x1e8 | u8 | 已观察训练组合的辅助标志，不是全模式分类器 |
| +0x20d0 / +0x2130 | 字符串对象 | 待加载双方名；不要直接覆盖成裸C字符串 |
| +0x2368 | s32 | 熊替换实验的P1配色设置点，限定已知配色 |

## 角色及关联数据

| 偏移/路径 | 类型 | 说明 |
|---|---|---|
| actor+0x88 | float | 队伍值，本次1=P1侧、2=P2侧 |
| actor+0x90 | float | 观察到的控制相关字段，**身份语义未完全验证** |
| actor+0xfc | float | 实际朝向，本次预期±1 |
| actor+0x120 | float | 生命，用于变化审计，不据此单独判命中 |
| actor+0x128..0x13c | float各项 | super/上限/每级、magic/上限/每级，必须核对缩放 |
| actor+0x324 / +0x328 | float | vx_local/vy，前者已是角色局部水平量 |
| actor+0x590起 | u32位字段 | Flag分组；本构建Flag27位0x08000000，不能覆盖整个字 |
| actor+0xc50 → data+0xb40 | pointer → 字符串 | 数据名；与选择层标识可能大小写不同 |
| actor+0xc58 → state+0x10 | pointer → 字符串 | 当前状态名；不等于动画帧号 |
| actor+0xc78 / +0xc7c | s32 | 本次观察x/y；还有其他同步位置，不建议直接裸写 |
| actor+0x1270 | u64 | 本次身份作用域的一部分，帮助识别对象代数变化 |
| actor+0xb30 | pointer | 父对象线索；只能在活对象集合内有界追踪 |
| actor+0x1262的0x40 | bit | 本次对象池失活检查之一，不是所有权证明 |
| actor+0x1260的0x08 | bit | 本次攻击活动条件之一；非活动时不乱解引用攻击数据 |

未列出的字段不是“不能研究”，只是本文没有给出足够结论。所有资源字段都要保留单位；例如奥莉和Velvet的魔力数值不能按同一固定上限解释。

## 类型映射中的纠错

本构建类型名映射函数0x18b34c0及跳转表提供：0 MULTIPLAYER_LOCAL；1 MULTIPLAYER_ONLINE；2 AI_VANILLA；3 AI_STORY；4 AI_ARCADE_STORY；5 AI_ARCADE_RANDOM；9 TUTORIAL；10 TRAINING；11 LEADERBOARD；12 CREDITS；13 STORE；14 GALLERY；15 NONE。6/7/8不赋予本文未确认语义。

这是名称映射，不是每种模式的测试证明。0在回放上下文也可能出现；11在旧工具注释中被当成联网并保守拒绝，名称证据不支持这个说法。不要把历史宽白名单复制成“全离线战斗均已验证”。

公开实现锚点与复现线索见[SOURCES.md](../SOURCES.md)，私密ASLR地址和完整转储不在本仓库。
